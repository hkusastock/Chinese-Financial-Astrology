# V8 Cross Analysis - Results Findings

## Scope
- Dataset: 4,928 trading days, 1,571 columns
- Baseline volatility: 0.01438
- Feature universe (cross-piece): 999 features

## Headline Findings
- 93 features increase volatility by more than 10%.
- 97 features suppress volatility by more than 10%.
- 147 features show strong directional bias (|net%| > 10).
- Strongest single-signal volatility boost appears in speed-position interaction.

## Strongest Volatility Boost Signals
- Mars stationary in Gemini: +94.6%
- Mars retrograde in Gemini: +89.7%
- Jupiter fast in Capricorn: +66.2%
- Venus fast × Mars retrograde: +46.8%
- Guan(sun_mars)=1: +32.5%

## Strongest Directional Bias Signals
- Mu guard count=2: strong bullish bias
- Chong(moon_saturn)=1: strong bearish bias
- Mu guard + Tu follow cross: strong bearish with high volatility

## Piece-Level Importance (Practical Priority)
- P0: Conjunction (BvC), Aspect (CvC), BvC aspect-count
- P1: Speed, Yunu, Changsheng
- P2: Pillars, Order/Phase, Wang-Shou

## Birth-Centric Findings
- Birth life master conjunction with selected current factors repeatedly appears in top boost group.
- Birth year-degree conjunctions contribute both extreme boosts and strongest suppressions.
- ASC/MC related conjunctions show stable direction-sensitive behavior.

## SHAP Highlights
- Elongation-family features are dominant in top SHAP ranks.
- `feat_year_degree` stays in high-importance region, validating year-degree relevance.
- Speed aggregate features (`speed_std`, `speed_weight_sum`) are consistently important.

## Data Quality Notes
- Speed field typo uses `retrogade` (not `retrograde`).
- Moon phase field has substantial missingness.
- Some strength quartiles are sparse and less stable.

## Modeling Targets (from V8 planning)
- Direction accuracy target: >= 76%
- Volatility MAE target: <= 0.0075
- Recommended ensemble: XGB + NN + RL + linear baseline

- Re-rank all cross-piece features using SHAP interaction values.
